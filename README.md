# ระบบบริหารจัดการโรงสีข้าวและคลังสินค้าอัจฉริยะ (Rice Mill & Inventory Management System)

**ผู้จัดทำ:** วณิชยา พันธ์สอาด (รหัสนิสิต: 67317347)

โปรเจกต์นี้เป็นแอปพลิเคชันสำหรับบริหารจัดการธุรกิจโรงสีข้าวขนาดย่อม พัฒนาด้วย **Flutter** (Frontend) และใช้ **Supabase** (Backend & PostgreSQL) เพื่อรองรับการจัดการข้อมูลการเงินและสต๊อกสินค้าแบบ Real-time

---

## 🛠 สิ่งที่ต้องมีก่อนติดตั้ง (Prerequisites)
- **Flutter SDK:** เวอร์ชัน 3.x ขึ้นไป
- **อุปกรณ์รันแอป:** โทรศัพท์มือถือ Android/iOS หรือ Emulator
- **ฐานข้อมูล:** บัญชี Supabase ที่สร้างตารางข้อมูลตาม Schema ของโปรเจกต์แล้ว
